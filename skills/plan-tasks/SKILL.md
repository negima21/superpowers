# Planning & Task Breakdown (Plan-Tasks)

> Alias for [`planning-and-task-breakdown`](../planning-and-task-breakdown/SKILL.md)

## Core Directive

Break down non-trivial features into ordered, bite-sized tasks before modifying codebase state.

## Operating Protocol

1. **Deconstruct**: Separate the overall objective into independent, self-contained milestones.
2. **Order & Dependencies**: Arrange tasks in dependency order so earlier tasks unblock later ones.
3. **Verification Criteria**: Define unambiguous verification steps for each task before starting execution.
