# Test-Driven Development (TDD)

> Alias for [`test-driven-development`](../test-driven-development/SKILL.md)

## Core Directive

Write failing automated tests before writing functional implementation code.

## Operating Protocol

1. **Red**: Write a unit or integration test defining expected behavior. Run it and confirm it fails for the expected reason.
2. **Green**: Write the minimal code required to pass the test. Run tests and confirm green.
3. **Refactor**: Clean up and optimize the implementation while keeping tests green.
